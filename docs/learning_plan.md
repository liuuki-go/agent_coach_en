# LangChain 与 Ollama 本地聊天项目学习计划

这份计划用于逐步完善基于 LangChain 与 Ollama 的本地英语聊天项目，同时学习职责划分、数据建模、故障恢复、测试和教学业务。继续采用模块化单体，每次完成一个范围明确、能够验证的小任务。

当前进度：第 01 项职责划分、第 02 项统一请求超时与界面恢复已完成；下一项是第 03 项请求状态与幂等协议，其余事项待开始。

完成规则：保留所有条目，完成后把对应的 `- [ ]` 改为 `- [x]`，并记录完成日期、修改范围和验证结果。仅创建目录、移动文件或通过模拟测试，不代表真实模型和数据库联调已完成。后续在本项目中完成任务时，同步更新本计划。

- [x] **02 统一请求超时与界面恢复**（2026-11-08 完成）

为列表、会话详情、历史同步和聊天请求明确超时与恢复行为。

验收：历史请求持续挂起或失败时，界面能够结束加载、保留已有回复和草稿，并允许恢复操作。

完成记录：

- `web_ui/api.js` 集中处理超时与外部取消：普通接口默认每次 10 秒，聊天默认 120 秒；支持 `timeoutMs` 覆盖。同一次等待覆盖请求和 JSON 响应体读取，超时后中止 fetch 并结束本地等待。
- 通过 `ChatApiError.code` 区分超时、用户停止、网络与 JSON 错误，保留 HTTP 状态和公开说明；请求完成后清理定时器及取消监听器，迟到响应不会覆盖当前结果。
- `web_ui/app.js` 统一使用请求层超时；读取失败保留原消息与草稿，聊天成功后历史同步超时仍保留回复并恢复操作，不自动重发聊天。
- 新建会话失败后提示结果未知；当前页面后续刷新空列表也不自动重复创建。这个保护不跨页面持久化，跨页面去重留给第 03 项幂等协议。
- 同步更新入口脚本与 API 模块缓存版本，并在 `web_ui/README.md` 记录默认值、恢复行为和边界。
- 验证：`node --test web_ui/tests/api.test.js web_ui/tests/ui.test.js` 共 68 项通过；`node --check web_ui/api.js`、`node --check web_ui/app.js` 和 `git diff --check` 通过。测试使用受控时钟和模拟后端，覆盖等待响应头或响应体、取消竞态、迟到结果、历史同步、新建未知和模型独立加载。
- 后端适配结论：现有接口路径、请求字段、响应格式和错误状态可直接配合，本项未修改后端。浏览器超时不代表后台已取消；模型网络、工具请求、数据库连接与取连接超时也不等于整轮执行总时限。真实数据库、Ollama 与浏览器联调尚未执行。
