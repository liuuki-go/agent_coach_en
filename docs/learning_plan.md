# LangChain 与 Ollama 本地聊天项目学习计划

这份计划用于逐步完善基于 LangChain 与 Ollama 的本地英语聊天项目，同时学习职责划分、数据建模、故障恢复、测试和教学业务。继续采用模块化单体，每次完成一个范围明确、能够验证的小任务。

当前进度：第 01—04 项的代码实现与隔离验证已完成；按用户选择先进入第 09 项，其中预算配置和临时输入选择已完成，摘要及真实效果比较待开展。第 05—08 项保持待开始。真实浏览器与 Ollama 联调尚未完成。

完成规则：保留所有条目，完成后把对应的 `- [ ]` 改为 `- [x]`，并记录完成日期、修改范围和验证结果。仅创建目录、移动文件或通过模拟测试，不代表真实模型和数据库联调已完成。后续在本项目中完成任务时，同步更新本计划。

- 启动时幂等回填已有成功请求；仅存在 Checkpoint 的更早记录需单独迁移，不能猜消息 ID、请求关联或真实发送时间。`created_at` 明确为归档时间；没有修改正式聊天数据。
